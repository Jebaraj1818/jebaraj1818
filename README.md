# 👜 Doddle Bags — Full-Stack E-Commerce Platform

> A real-world e-commerce platform developed for an entrepreneur and her handmade bag business.

🌐 **Live Website:** https://doddle-bags.vercel.app/

---

## 📌 About the Project

**Doddle Bags** is a full-stack e-commerce platform developed to provide a complete online shopping experience for a handmade bag business.

The project was built around a real business use case, covering both the customer-facing shopping experience and the administrative operations required to manage an online store.

This project gave me hands-on experience in turning business requirements into a functional web application while working with authentication, databases, APIs, payments, notifications, security and deployment.

---

## ✨ Key Features

### 🛍️ Customer Features

* Product browsing and search
* Product details and image galleries
* Wishlist
* Shopping cart
* Recently viewed products
* Customer registration and login
* Address management

* Product reviews

* Order status updates

* Password reset notifications

### 👨‍💼 Admin Dashboard
